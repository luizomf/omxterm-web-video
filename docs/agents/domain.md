# Domain docs

This repository uses a single-context documentation layout.

Before exploring, read root `CONTEXT.md` and relevant records under `docs/adr/`
when they exist. Their absence is not a blocker; proceed silently until a real
domain term or durable architecture decision needs to be recorded.

Use terminology defined by `CONTEXT.md` in issues, tests, and documentation.
Surface conflicts with an existing ADR explicitly instead of silently
overriding it.
